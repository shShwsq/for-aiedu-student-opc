## 二、体验流程

1. **登录**：打开地址 → 用第二节账号登录。**请优先用给定测试账号**；自行注册需邮箱验证，演示环境可能收不到邮件。
2. **浏览成品**：进入任务列表 → 打开预置的“商业计划书审查”任务 → 点右侧竖栏图标展开「核查与结果」栏，看「审查结果」段（逐条审查项，含结论、证据与严重度；结论以大白话写成）与「重点与知识点」段；如需留存可「下载 Markdown 报告 / 导出 PDF」。
3. **看检查助手**：同一侧栏 → 「概览」段的「建议追问方向」、「核查过程」段的核查时间线；点某条「建议追问方向」的「追问」即触发新一轮。
4. **知识点看板 → 练习**：进入练习/看板页 → 展开知识点讲解 → 选一道题作答 → 看判分与解析。
5. **（可选，会消耗额度）自己跑一个任务**：提交任务 → 上传 ZIP/单文件或填仓库地址 → 选择执行器（内置 AI助手，或 Qoder/DeepSeek/Codex CLI）→ 观察流式推理与工具调用。
